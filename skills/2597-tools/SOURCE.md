# tools

Werkzeuge mit ausschließlich expliziter Auslösung: /tools:ask und /tools:execute (die jeweils andere CLI non-interaktiv fragen bzw. beauftragen), /tools:unslop (KI-Muster aus Text entfernen), /tools:grimm (Sachverhalte ins Verwaltungs- und Anordnungsdeutsch überführen), /tools:orchestrator[-review|-cross] (Rollen-Prompt: steuern statt arbeiten, in drei Stufen bis zur anderen CLI als Arbeiter). Nachfolger der Plugins ask, unslop und grimm.
