# oxlint

oxlint — the extremely fast (Rust) JavaScript/TypeScript linter from the oxc project, an ESLint alternative that needs no config to start. Use when linting JS/TS/JSX/Vue, writing `.oxlintrc.json`, selecting rules via `plugins` + `categories` (correctness, suspicious, pedantic, perf, style, restriction, nursery), running `--fix`/`--fix-suggestions`/`--fix-dangerously`, suppressing with `// oxlint-disable`, or migrating from ESLint. The linter — not oxfmt, ESLint/Biome, or ruff.
