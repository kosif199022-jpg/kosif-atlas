# frontend-orchestrator-kit

Frontend-only sequencer: spec-dev-kit to author a spec, html-generator-kit to prototype it, then feature-dev-kit once per feature (nested screen-tasks share that call) against a persisted, resumable checklist. Use app-orchestrator-kit /orchestrate-app for the full-stack dispatcher.
