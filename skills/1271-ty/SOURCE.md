# ty

ty — Astral's extremely fast (Rust) Python type checker and language server, in 0.0.x beta. Use when running or configuring `ty check`, reading ty diagnostics, setting rule levels in `[tool.ty]`/`ty.toml`, writing `# ty: ignore[rule]` suppressions, debugging environment or module-resolution failures, wiring ty into CI (exit codes, `--output-format github`), or migrating from mypy/pyright. Pinned to ty 0.0.72. The type checker — NOT ruff (lint/format) or uv (packaging).
