## Original direction (historical, rejected)

Governing skill: Frontend Design Director v0.3. Classic frontend-design was not used.

Concept: this site should feel like a flight recorder because developers need to reconstruct an agent's failure, not admire an abstract AI animation. Product-led SaaS with developer-tool evidence. All runs and product claims are fictional demonstrations, not connected observability services.

Selected composition: left-aligned 76px statement, a broad dark execution instrument, then a sparse explanatory heading above one large context artifact and two supporting crops. Finish in warm paper with a working before/after replay. Rejected: a full-screen glowing network graph; its spatial complexity would obscure the actual source failure and repeat generic AI imagery.

References: the measured Cursor study supports a large product stage and quiet chrome; Linear supports following the same work object through distinct chapters; Firecrawl supports an executable concept near the proposition. These are original adaptations of measured principles, not copied layouts or claims of new live inspection.

Typography: Archivo for prose/display, IBM Plex Mono for technical labels and artifacts; exactly two local font families. Palette: ink #10110f, warm paper #f1efe7, amber #e8b56a for failure and intervention. 1184px content width; 48px desktop / 22px mobile margins. 1.4:1 evidence grid; hero inspector 310px, timeline fluid. No external font requests.

Story: wrong answer → failed tool span → stale policy evidence → corrected source → replayed answer. Inspecting a span changes its details, without fabricating a new run. Replay reads a native select; stale policy reproduces the failure, current policy returns the corrected fixture. Changing the source invalidates the prior replay. Reset returns the original run. No account, payment, API, or data upload is involved.

Mobile: replace the desktop timeline's duration lanes with a compact vertical execution list; retain stage status and timing. Keep a focused source-document crop and a two-cell supporting row. Render comparison results as a vertical pair, without horizontal page scrolling. Static content is visible without scripts; dynamic controls are disabled until initialization. Motion is limited to a short run-path reveal and state feedback, removed under reduced-motion preference.
