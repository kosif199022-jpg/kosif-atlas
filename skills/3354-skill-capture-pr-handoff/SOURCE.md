# skill-capture-pr-handoff

Land a newly captured skill through the ONE peer session already working the skills repo: capture side authors skills/<name>/ content only (never registry files), leak-screens it, pushes branch add-skill-<name> and messages that single session; landing side does registry, versions, validators, PR. Falls back to claudeception's own wiring when no such peer exists.
