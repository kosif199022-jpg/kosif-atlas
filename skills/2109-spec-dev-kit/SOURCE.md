# spec-dev-kit

Multi-agent pipeline that turns raw requirements in .spec/context/ into a validated, human-approved hybrid YAML+Markdown spec — requirements register with coverage, roles, permissions, rules, state machines, and a step-by-step delivery plan with per-slice build briefs — read by html-generator-kit, feature-dev-kit, backend-dev-kit, agent-dev-kit, and both orchestrators.
