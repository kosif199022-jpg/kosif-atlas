# lf-output-formatter

LFX Marketing OS shared output formatter: builds every agent's deck, document, or letter on the three approved Linux Foundation templates (LF 2025 Google Slides template, LF Agent DOCS template, LF Letterhead) and, for foundation-specific documents, re-skins the template with the foundation's Brand Kit — logo, palette, typography, iconography. Includes the bundled templates, build scripts, a Brand Kit extractor, and a render-and-check step.
