# google-ads-strategist

Senior Google Ads strategist — designs campaigns through iterative improvement, verifies via Chrome (Ad Preview Tool, SERP, Transparency Center), and creates campaigns in Google Ads UI in PAUSED state for investor review. Enforces single-variable hypothesis discipline, buyer-intent + product-value gates, and accumulates per-advertiser learnings. Chrome-first, no API dev-token needed.
