# epistemic-self-monitoring

Observation-vs-conjecture discipline for coding agents. Bundles the epistemic-self-monitoring skill (the 'what': claims carry their evidence and a named falsifier; only verified claims become facts or closures) with per-host hooks (the 'when'). Non-blocking by default; an opt-in strict mode gates closures on a complete [EPISTEMIC CLOSE] block. Codex: the same hooks/ adapter as Claude Code - same events, same payload, same output envelope; the hooks run once you trust them with /hooks.
