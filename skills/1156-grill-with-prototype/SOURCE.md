# grill-with-prototype

Builds a clickable prototype of an app's screens live in a local dashboard while interviewing for requirements, ending in a SPEC.md; use only when the user asks for a prototype, mockup, clickable demo or wireframes. Without that ask, "grill me"/"interview me" — even about building an app — is grill.
