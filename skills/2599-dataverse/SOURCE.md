# dataverse

Microsoft Dataverse / Dynamics 365 Sales via the myHub-hosted OAuth MCP gateway. 38 tools across accounts, contacts, leads, and opportunities — CRUD plus first-class Sales actions (qualify lead, win/lose opportunity, merge, assign), activities (task/phonecall/email/appointment), notes, FetchXML, and metadata. Multi-environment per user — picks up every Dataverse org the signed-in user can access.
