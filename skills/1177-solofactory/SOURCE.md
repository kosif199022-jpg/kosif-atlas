# solofactory

Installs and operates SoloFactory, a local-first software factory (interview → PRD → subscription-backed build → gates → local deploy) as a folder's agentic function with each project a git repo under projects/ or the root; use for "set up solofactory here", "make this folder a software factory", "start the factory", "update my solofactory".
