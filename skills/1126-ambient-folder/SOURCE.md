# ambient-folder

Makes a folder ambiently intelligent and maintains it — interviews for purpose when it's unclear, writes the .aai/ scaffold, vendors canonical capabilities into .ailib/, forks them, re-syncs; use for "make this folder ambient", "set up an agentic folder for X", "stamp .aai here", "interview me about this folder", "add a capability to this folder", "re-sync my vendored skills".
