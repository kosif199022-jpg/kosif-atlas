# retrieval-review

Audit a retrieval / vector-index pipeline for structural health across seven layered axes — eval foundation, corpus & chunking, embedding geometry, index & ANN fidelity, retrieval composition, rank fusion, and reranking — and flag the defects that silently return wrong or missing context before they reach the generator.
