# Work with Translation Files

Source: https://v20.angular.dev/guide/i18n/translation-files

## Overview

Use `ng extract-i18n` to extract marked text into a *source language file*, then create and translate per-locale files.

### Steps

1. Extract the source language file
2. Copy it to create a translation file for each language
3. Rename: `messages.xlf` → `messages.{locale}.xlf`
4. Translate each file
5. Translate plurals, alternate expressions, and nested expressions separately

---

## Extract the Source Language File

```bash
ng extract-i18n
```

Default output: `messages.xlf` in the project root directory (XLIFF 1.2 format).

### Options

| Option | Details |
|--------|---------|
| `--format` | Set output format |
| `--out-file` | Set output filename |
| `--output-path` | Set output directory path |

### Change output path
```bash
ng extract-i18n --output-path src/locale
```

### Supported formats

| Format | Details | Extension |
|--------|---------|-----------|
| ARB | Application Resource Bundle | `.arb` |
| JSON | JavaScript Object Notation | `.json` |
| XLIFF 1.2 | XML Localization Interchange File Format v1.2 | `.xlf` |
| XLIFF 2 | XML Localization Interchange File Format v2.0 | `.xlf` |
| XMB | XML Message Bundle | `.xmb` (source) / `.xtb` (translation) |

```bash
ng extract-i18n --format=xlf
ng extract-i18n --format=xlf2
ng extract-i18n --format=xmb
ng extract-i18n --format=json
ng extract-i18n --format=arb
```

### Change output filename
```bash
ng extract-i18n --out-file source.xlf
```

## Create a Translation File for Each Language

1. Run `ng extract-i18n`
2. Copy `messages.xlf` → `messages.fr.xlf` (for French)
3. Move to `src/locale/`
4. Send to translator

---

## Translate Each Translation File

In XLIFF format, a translation unit looks like:

```xml
<trans-unit id="introductionHeader" datatype="html">
  <source>Hello i18n!</source>
  <note priority="1" from="description">An introduction header for this sample</note>
  <note priority="1" from="meaning">User welcome</note>
</trans-unit>
```

After translation, add a `<target>` element:

```xml
<trans-unit id="introductionHeader" datatype="html">
  <source>Hello i18n!</source>
  <target>Bonjour i18n !</target>
  <note priority="1" from="description">An introduction header for this sample</note>
  <note priority="1" from="meaning">User welcome</note>
</trans-unit>
```

> **IMPORTANT:** Never change the `id` attributes — they are generated by Angular based on content and meaning. Changing text or meaning generates a new ID.

---

## Translate Plurals

Translate each ICU plural match value in the `<target>`:

```xml
<trans-unit id="5a134dee893586d02bffc9611056b9cadf9abfad" datatype="html">
  <source>{VAR_PLURAL, plural, =0 {just now} =1 {one minute ago} other {<x id="INTERPOLATION" equiv-text="{{minutes}}"/> minutes ago} }</source>
  <target>{VAR_PLURAL, plural, =0 {à l'instant} =1 {il y a une minute} other {il y a <x id="INTERPOLATION" equiv-text="{{minutes}}"/> minutes} }</target>
</trans-unit>
```

Add or remove plural cases as needed per language's plural rules (see [CLDR plural rules](https://cldr.unicode.org/index/cldr-spec/plural-rules)).

---

## Translate Alternate Expressions (select)

Angular extracts `select` ICU expressions as **two separate translation units**:

1. The text outside the `select` clause (with a placeholder `<x id="ICU">`)
2. The `select` clause itself

> **IMPORTANT:** Don't remove the `<x id="ICU">` placeholder — it embeds the ICU expression. Move it if needed but never delete it.

---

## Translate Nested Expressions

Angular extracts nested ICU expressions the same way — into two units:

1. The outer expression with a placeholder for the inner ICU
2. The complete nested expression

Translate both `<target>` elements independently.
