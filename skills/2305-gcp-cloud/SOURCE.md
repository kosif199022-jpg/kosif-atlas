# gcp-cloud

Google Cloud (GCP) infrastructure & platform team — agents (gcp-architect, gcp-iam-engineer, gcp-network-engineer, gcp-data-and-compute-engineer) for the GCP layer of a stack: the resource hierarchy (organization/folders/projects) and org policy constraints, least-privilege IAM (predefined over primitive roles, service accounts + Workload Identity Federation, no key files), VPC networking (Shared VPC, firewall rules, Private Service Connect, Cloud NAT), compute selection (Cloud Run / GKE / Cloud Run functions / GCE), and the data services (BigQuery, Pub/Sub, Cloud SQL) at a selection level. skills, a decision-tree knowledge bank (compute-selection + project-hierarchy trees + a dated 2026 capability map), best-practices, templates, commands, an advisory hook. Multi-cloud seam to aws-cloud/azure-cloud; IaC -> terraform-iac; BigQuery analytics -> data-platform; security verdicts -> ravenclaude-core/security-reviewer. Requires ravenclaude-core@>=0.7.0.
