# html-generator-kit

Turns a validated spec-dev-kit spec into a clickable Alpine.js multi-page HTML prototype (CDN-free for styling; Alpine and Google Fonts load from a CDN). A provided theme, brand, style guide, mockup, or layout is binding; ui-ux-pro-max supplies the design direction only when none is provided. Headless-browser verified before the skill-owned review gate.
