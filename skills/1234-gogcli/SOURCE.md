# gogcli

Drive Google Workspace from the terminal with the `gog` CLI (gogcli). Use when sending/searching Gmail, managing Calendar events, uploading to Drive, editing Docs/Sheets/Slides, posting to Chat, managing Tasks/Contacts, administering Workspace via DWD, or building agent workflows needing JSON output, OAuth/service-account auth, Pub/Sub watches, and a command sandbox. Covers Gmail, Calendar, Drive, Docs, Slides, Sheets, Chat, Tasks, Contacts, Classroom, Forms, Keep, Admin.
