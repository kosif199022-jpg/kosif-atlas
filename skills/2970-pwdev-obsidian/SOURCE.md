# pwdev-obsidian

Integração com Obsidian via servidor MCP embutido no plugin comunitário Local REST API (HTTPS local, self-assinado) — leitura, escrita e edição estruturada de notas (heading/block/frontmatter), busca por JsonLogic e por texto livre, tags, arquivo ativo e comandos da paleta. Panorama só-leitura do vault. Setup guiado com API Key fora do repositório.
