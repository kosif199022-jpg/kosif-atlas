# model-routing

Install and maintain a "model routing" section in a project's CLAUDE.md that teaches Claude Code which model to use for which work, including delegating to GPT models via the Codex CLI. Use when adding model-picking guidance to CLAUDE.md, setting up Codex/GPT as a delegation target or fallback, or routing subagent and workflow tasks across models by cost, intelligence, and taste.
