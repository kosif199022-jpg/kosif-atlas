# code-walkthrough

Create self-contained interactive HTML documents that teach a code change (branch, PR, diff, subsystem) to a reviewer with no prior knowledge — before/after code toggles, mermaid diagrams, step-through code walkers, and playground widgets. Use when the user wants an interactive walkthrough/teaching document of a branch or PR, before/after visuals, or to learn a codebase area from zero.
