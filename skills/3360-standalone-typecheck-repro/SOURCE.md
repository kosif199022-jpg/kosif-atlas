# standalone-typecheck-repro

Typecheck a TypeScript change without installing a large monorepo's node_modules: rebuild a minimal standalone repro at the repo's pinned compiler version, run orig/broken/fixed variants, and check exit codes so a crashed tool cannot read as a clean pass.
