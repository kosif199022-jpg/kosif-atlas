# apply

Browser-driven job application copilot — locate matching postings, score fit, tailor resume/cover letter/screening answers per job to score well on real evaluator engines (Workday HiredScore, Taleo, iCIMS, Ashby, LinkedIn, LLM screeners) with a deterministic keyword-coverage check, drive the application form with a human confirmation gate before every submit, and track the pipeline locally.
