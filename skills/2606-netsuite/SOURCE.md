# netsuite

Oracle NetSuite ERP via the myHub-hosted TBA (OAuth 1.0a) MCP gateway. Tools across accounts, contacts, customers, SuiteQL querying, and dashboard analytics — revenue summaries, AR aging, open sales orders, cash position, and top customers. Requires five TBA credentials: account ID, consumer key/secret, token ID/secret.
