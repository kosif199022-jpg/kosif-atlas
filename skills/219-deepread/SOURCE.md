# deepread

Evidence-first reading of supplied documents — books, articles, PDFs, document sets. Five modes (quick, deep, map, feynman, book), claim/reason/evidence decomposition with four-level confidence labels, an evidence ledger, knowledge maps, and Feynman teach-back. Starts from material the user supplies; for discovering sources across the web use deep-research, and for citation-formatted briefs use research-summarizer.
