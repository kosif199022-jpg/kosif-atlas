# termination-self-monitoring

Checkable-reason discipline for stopping, deferring, narrowing or softening. Bundles the termination-self-monitoring skill (the 'what': a state-shaped reason - fatigue, clock, context budget, confidence as a feeling, difficulty as a mood, a run of apologies - is replaced by a checkable one: gate-not-run, owner-choice, budget-spent, limit-observed, or none and continue) with per-host hooks (the 'when') that scan the final message for those persona artifacts and for the [TERMINATION CHECK] block. Non-blocking by default; TERMMON_STRICT=1 blocks once. Codex: the same hooks/ adapter as Claude Code - same events, same payload, same output envelope; the hooks run once you trust them with /hooks.
