# cognitive-mirror

Live extractor for the user's cognitive profile — observes the current or recent conversations to model how they think, decide, and evaluate; 5 modes /loms (current chat), Mine (recent chats), Diff, Query, Harvest (decision instances for DSPy); use for "/loms", "look over my shoulder", "mine my conversations", "update my cognitive profile", "harvest my decisions", "how do I typically approach X", "what's my pattern when". Prefer deep-mirror for bulk raw-log mining, scheduling, or auditing. Data lives in ~/.aai/.
