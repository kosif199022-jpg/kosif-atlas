# all-skills

Meta-plugin that installs every mnox-ai agentic-review skill at once via plugin dependencies. Standalone utility plugins (session-tracker, config-chunks, create-skill, bash-gate) are installed separately. Excludes foundry, which is decommissioned for public use.
