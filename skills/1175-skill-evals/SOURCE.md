# skill-evals

Runs one skill's existing evals/evals.json — triggering cases against a fresh subagent, quality cases judged against prose pass criteria — and reports a PASS/FAIL table, no scores; use for "run the evals for X", "test this skill's evals", "does X still trigger right".
