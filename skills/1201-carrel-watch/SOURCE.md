# carrel-watch

Watch folders and file inboxes with the carrel CLI: /watch-folder runs actions on file events (recursive, settle-wait, polling, done/error dirs, service definitions); /intake reads each arriving document, names it, files it by date or fiscal period, indexes it and tags it with its reference numbers. Plus a watch-automation recipe skill.
