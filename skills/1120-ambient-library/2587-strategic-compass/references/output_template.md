# Output Template — Field Definitions

## RECOMMENDED PATH
- Name the approach (not the outcome) — e.g. "Direct channel launch" not "grow revenue"
- State why it's stronger by referencing the user's specific situation
- One or two sentences max

## WHY NOT THE ALTERNATIVE
- Name the discarded approach
- State the single weakest point — the thing that most directly undermines it
- Must be grounded in what the user said, not generic criticism

## NEXT 30 DAYS
- 3 bullets, no more
- Each bullet: action + owner (if team context exists) + implicit deadline
- Actions must be executable, not directional ("call the supplier" not "improve supply chain")

## WATCH FOR
- One trigger condition that would change the recommendation
- Must be specific and observable (not "if things change")
- Follow with: "If this happens: [alternative path]"

## CONFIDENCE
- High: strong context, clear decision, user's constraints are known
- Medium: some ambiguity in the situation or gaps in what the user shared
- Low: significant unknowns; recommendation is directional, not definitive
- Always state what would raise the confidence level if Medium or Low
