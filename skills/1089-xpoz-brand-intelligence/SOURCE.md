# xpoz-brand-intelligence

Brand intelligence analysis using XPOZ MCP social data. Includes 3 skills: brand-snapshot (sentiment, narratives, SWOT), brand-competition (share of voice, competitive positioning), and brand-influencers (influencer discovery, partnership opportunities). Analyzes real-time Twitter/X data for actionable brand insights.
