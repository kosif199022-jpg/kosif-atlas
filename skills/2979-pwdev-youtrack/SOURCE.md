# pwdev-youtrack

Integração com YouTrack Cloud via MCP oficial embutido (2025.3+) — issues CRUD, busca com query language, comentários, tags, artigos da knowledge base e log de trabalho. Fallback REST autenticado para o que o MCP não cobre: agile boards, sprints, relatórios de tempo, anexos e operações em lote. Setup guiado com token fora do repositório.
