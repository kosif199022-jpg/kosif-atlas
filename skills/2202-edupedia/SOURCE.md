# edupedia

TEDY edupedia ince istemcisi (1.1.0) — Türkiye Yüzyılı Maarif Modeli'ne hizalı, WCAG 2.1 AA, Tedy tasarım dilinde (IBM Carbon v11) etkileşimli öğrenim modüllerini tedy MCP orkestratörüyle (mcp.tedy.online; interaktif OAuth, yalnız TEDY aile listesi) üretir; modüller 18 kalite kapısından geçip tedy.online aile kataloğunda yayınlanır. start + edupedia skill'leri, beş komut (/edupedia:modul, /edupedia:mufredat, /edupedia:kazanim-bul, /edupedia:soru, /edupedia:durum) ve tedy-yalnız SessionStart preflight. maarif-mufredat ve egitim-kaynak isteğe bağlı doğrudan bağlayıcılar. claude.ai, Codex, Grok ve Gemini Spark paketleri surfaces/ altında tek başlangıç talimatından türetilir. 1.1.0 — Tedy ders renk sistemi: her ders modülde, panoda ve katalogda aynı Carbon Tag ailesiyle görünür (Türkçe/edebiyat magenta · matematik mor · fen teal · sosyal camgöbeği · yabancı dil mavi); görünüm tamamen orkestratördedir — MODULE_DATA'ya renk, tema ya da CSS yazılmaz, meta.accent yalnız ders ailesi adı olabilir. 1.0.0'dan beri yerel HTML teslimi yoktur; tek yayın yolu tedy.online. Kapsam yalnız Türkiye MEB.
