# connector-bridge

Resolves a folder's declared .aai/connectors.md needs against whatever the current harness actually offers (MCP tools, CLIs, or nothing), caching successful matches in .aai/memory/; use for "wire up this connector", "resolve connectors.md", "what can reach X here".
