# poppify

Claude Code plugin for photo-led short-form vertical reels — Instagram / TikTok / YouTube Shorts / Facebook. Upload 1–10 photos, get a captioned 15/30/60s reel with motion, library-matched music, optional voiceover. $0.06 base render, 50 free seeds, no subscription.
