# k3s

The k3s lightweight CNCF-certified Kubernetes distribution as a single binary (bundles containerd, flannel, CoreDNS, Traefik, ServiceLB, local-path-provisioner, metrics-server). Use when installing/running a lightweight cluster, bootstrapping single-node or HA control planes, joining agent nodes, embedded etcd vs external datastore, managing tokens, rotating certs, etcd snapshots, secrets encryption, airgap installs, disabling components, or upgrading k3s. Includes `(k3s vX.Y+)` annotations.
