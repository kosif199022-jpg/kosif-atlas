# empirical-analysis-stata

Explicit 8-step empirical-analysis pipeline in the traditional Stata ecosystem (reghdfe + ivreg2 + csdid + did_imputation + eventstudyinteract + sdid + rdrobust + synth + psmatch2 + teffects + esttab + coefplot). From use / import all the way to .tex / .rtf tables and .pdf figures, with the full modern DID toolkit (bacondecomp + honestdid + rwolf + ritest). Also covers epidemiology and ML-causal (ddml / crforest) modes. The first choice when a referee or co-author insists on a Stata replication pack.
