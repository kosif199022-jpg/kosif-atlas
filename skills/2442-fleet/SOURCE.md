# fleet

Agent-to-agent reach across a personal fleet: from any Claude Code lane (WSL or native Windows, on any machine) run a script, prompt, query and wait, message a session, or start a named session in any other lane. Each lane signs into its own Claude account, so the built-in peer tools see only their own lane; this carries the route matrix that starts a headless turn inside the target lane, target resolution from the rendered fleet manifest, and the permission posture that keeps agent launches prompting.
