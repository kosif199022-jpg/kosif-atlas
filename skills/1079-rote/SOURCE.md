# rote

Compile a proven skill (a SKILL.md plus references) into a deterministic pipeline that runs without an LLM in the loop. /rote:compile emits DBOS, Temporal, Cloudflare Workflows, Inngest, or plain Python/TS; /rote:serve exposes the compiled pipelines back to Claude as MCP tools.
