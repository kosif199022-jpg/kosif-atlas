# claude-math

Emit mathematics as inline Unicode (∑, ≤, ℝ, x², matrices, set-builder) instead of LaTeX, so equations stay legible in the Codex TUI and Unicode-capable terminals. Copy- and search-safe. Also works in Claude Code.
