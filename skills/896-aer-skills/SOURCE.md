# aer-skills

Agent skill stack for the American Economic Review, AER: Insights, and AEJ family. Covers topic selection, literature positioning with citation verification, modern causal identification (DiD / IV / RDD / SCM / Bartik), experimental pre-registration with power/MDE sizing, referee-anticipating robustness, body-section drafting with magnitude discipline, Keith-Head-style introductions, AER booktabs tables, full-manuscript consistency audits, adversarial referee simulation, AEA Data and Code Availability deposits, submission preflight, and R&R rebuttal letters. Includes Stata / R / Python templates, an optional StatsPAI agent-native implementation engine, and classic-AER-paper exemplars.
