# chrome-localhost-mic-autoblock

Fix a web app's mic failing in Chrome with a `not-allowed` error on localhost even though the OS granted Chrome mic access: Chrome auto-blocks the mic per-site, and the OS Privacy toggle / Chrome restart never clears it. Set the site to Allow.
